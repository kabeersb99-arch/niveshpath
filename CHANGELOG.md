# Changelog

## 1.0.0 (16 Nov 2026) - Phase 4
- Offline mode verified: the app and the last data load with no connection; an "offline" notice shows the data time.
- Data health: per-feed last-good time, error text, consecutive-failure count, aged hand-entered rates, count of unverified items, "check for app update".
- Admin alert: the data job fails (and GitHub emails the owner) when a feed is down on two runs in a row.
- End-to-end test of the data job against a local server; browser smoke test with an offline check.
- "New" badges for Update cards, backup reminder, print / save-as-PDF layout, lessons flagged for revision when facts are re-reviewed.
- MAINTAIN.md: how to maintain the app without coding.
